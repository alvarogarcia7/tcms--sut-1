# Document templates

Templates used to render the verification and validation documents of the
`traceability-document` job (`scripts/traceability-document.sh`). Nothing here is generated by
the pipeline.

| Folder | Used for | Source |
|---|---|---|
| `test_results/` | The outer document (`test_container_result.md.j2`, `test_container_result.adoc.j2`), the container schema (`container_schema.json`) and the traceability matrix (`traceability_matrix.md.j2`, `traceability_matrix.adoc.j2`). | Copied from `data/test_results/` of [test-plan-documentation-generator](https://gitlab.crypto.tii.ae/b3/hardware-kms/test-plan-documentation-generator) at commit `58c4a890e8b0acda744c916902934792bad66f32`, except as listed below. The matrix templates are written for sut-1. |
| `verification_methods/` | One folder per verification method (`analysis`, `common_criteria`, `demonstration`, `high_assurance`, `inspection`, `result`, `test`), each with `schema.json`, `template.j2` and `template_asciidoc.adoc`. The `result` folder renders each test case (`test_cases_md`). Plus `requirement_aggregation_template.{j2,adoc}`, not used. | Copied from `data/verification_methods/` of the same repository and commit. |

Changes to the copies in `test_results/`:

- `container_template.j2`, `container_template_asciidoc.adoc`, `test_container_result.md.j2`
  and `test_container_result.adoc.j2`: the "Requirements Summary" section, which needs
  `requirements_summary_md` and has no source, is now "Traceability Matrix" and renders
  `traceability_matrix_md`.

The other files are unchanged. To update the copies, copy again from the source commit, record
the new commit in this table and redo the change above.

Not copied: the `sample_*` test results and the `data/input_data/`, `data/DO-178C/`,
`data/strictdoc/` and `data/logging_example/` folders of the same repository.
